Sigenergy dashboard for the Waveshare ESP32-S3-Touch-LCD-4.3B – solar, battery, energy prices and earnings.

Ta przeglądarka nie obsługuje instalacji. Użyj Chrome lub Edge na komputerze. This browser can't install. Use Chrome or Edge on a computer. Strona musi być otwarta przez https.The page must be opened over https.
Jak zainstalować
  1. Podłącz płytkę kablem USB-C do komputera (tym samym złączem, którym zwykle ją programujesz).
  2. Kliknij Zainstaluj na płytce i wybierz port płytki z listy.
  3. Przy pierwszej instalacji zaznacz Wymaż urządzenie. Przy aktualizacji nie zaznaczaj – zostaną ustawienia i historia.
  4. Po ok. minucie płytka uruchomi się sama. Na ekranie wybierz sieć Wi-Fi – SigDash sam znajdzie Sigenergy.

Jeśli port się nie pojawia: przytrzymaj BOOT, naciśnij RESET, puść BOOT i spróbuj ponownie.
W Sigenergy musi być włączony Modbus TCP (aplikacja mySigen). SigDash tylko odczytuje dane – niczego nie zmienia w falowniku.

How to install
  1. Connect the board to the computer with a USB-C cable (the port you normally program it through).
  2. Click Install on the board and choose the board's port.
  3. On the first install tick Erase device. For updates leave it unticked – settings and history stay.
  4. After about a minute the board restarts. Choose your Wi-Fi on the screen – SigDash finds Sigenergy by itself.

If no port shows up: hold BOOT, press RESET, release BOOT and try again.
Modbus TCP must be enabled in Sigenergy (mySigen app). SigDash only reads data – it never changes the inverter.
